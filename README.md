# 🎙️ Voice Assistant Web Application

A web-based Voice Assistant that uses Speech Recognition and Text-to-Speech to interact with users in real time.

## 🚀 Features
- Voice command recognition
- Speech response system
- Real-time interaction
- Simple UI with HTML, CSS, JavaScript

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript (Web Speech API)


## 📌 How to Run
Open index.html in browser
